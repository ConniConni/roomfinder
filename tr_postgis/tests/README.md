# PostGIS データ抽出プロジェクト

## 1. ディレクトリ構造

プロジェクト全体の構成は以下の通り。

```text
.
├── .env                            # DB接続情報、機密情報（ルート直下）
├── tr_postgis/                     # プログラム本体
│       ├── README.md               # プロジェクトの概要説明
│       ├── config.py               # 設定管理・ロギング
│       ├── sample_postgis_1.py     # メインロジック
│       ├── tests/                  # ユニットテスト
│       │    ├── __init__.py
│       │    ├── test_config.py
│       │    └── test_sample_postgis.py
│       ├── result/                 # 実行結果(取得ファイル)出力先
│       │    └── extraction_point.csv
│       └── log/                    # 実行ログ出力先
```

---

## 2. モジュール定義

各モジュールの責務と提供する主要関数。

### tr_postgis/config.py

| 関数名            | 引数 | 戻り値 | 説明                                               |
| :---------------- | :--- | :----- | :------------------------------------------------- |
| `setup_logging()` | なし | なし   | ログフォルダの作成と初期設定を行う。               |
| `get_db_config()` | なし | `dict` | `.env` から情報を取得。不足があれば `SystemExit`。 |

### tr_postgis/sample_postgis_1.py

| 関数名                 | 引数        | 戻り値 | 説明                                   |
| :--------------------- | :---------- | :----- | :------------------------------------- |
| `connect_db()`         | `dict`      | `conn` | PostgreSQL(PostGIS)への接続を確立。    |
| `fetch_data_from_db()` | `conn, str` | `list` | 空間検索クエリを実行。                 |
| `save_to_csv()`        | `str, list` | なし   | 結果をCSV保存。0件時は保存をスキップ。 |
| `main()`               | なし        | なし   | メイン処理。                           |

## 3. テスト仕様

`pytest` による検証観点を定義する。

### 3.1 config.py 検証 (ID: C-XXX)

| ID   | 分類 | テスト項目（観点）                       | 期待される結果                                |
| :--- | :--- | :--------------------------------------- | :-------------------------------------------- |
| C-N1 | 正常 | 全項目（HOST/PORT/DB/USER/PASS）設定済み | 正しく辞書形式で返却されること                |
| C-N2 | 正常 | `POSTGRES_HOST` が未設定                 | デフォルト値 `localhost` が適用されること     |
| C-E1 | 異常 | `POSTGRES_PORT` が未設定                 | エラーログ出力後、ステータス 1 で終了すること |
| C-E2 | 異常 | `POSTGRES_DB` が未設定                   | エラーログ出力後、ステータス 1 で終了すること |
| C-E3 | 異常 | `POSTGRES_USER` が未設定                 | エラーログ出力後、ステータス 1 で終了すること |
| C-E4 | 異常 | `POSTGRES_PASSWORD` が未設定             | エラーログ出力後、ステータス 1 で終了すること |
| C-E5 | 異常 | 複数の必須項目が未設定                   | 全不足項目がログに含まれ、ステータス 1 で終了 |

### 3.2 sample_postgis_1.py 検証 (ID: S-XXX)

| ID   | 分類 | テスト項目（観点）           | 期待される結果                                 |
| :--- | :--- | :--------------------------- | :--------------------------------------------- |
| S-N1 | 正常 | 有効なデータリストの保存     | ファイルが作成され、ヘッダーと内容が正しいこと |
| S-N2 | 正常 | 0件データの保存              | ログ出力され、ファイル作成がスキップされること |
| S-E1 | 異常 | 書き込み権限のないパスを指定 | `IOError` 等の例外が発生すること               |
| S-E2 | 異常 | 不正な接続情報でDB接続       | `psycopg2.Error` 系の例外が発生すること        |

---

### テスト実行方法

`tr_postgis` ディレクトリに移動し、以下のコマンドを実行する。

```bash
cd tr_postgis
pytest
```
